# Project Roadmap

This roadmap outlines planned future improvements for the TV Parser player shell.

---

## Phase 1: Android TV Focus & UI Refinements
- [ ] **Banner Customization:** Add configurable asset paths for Android TV home screen banners and launcher channels.
- [ ] **D-pad Navigation Tuning:** Polish diagonal movements on grid lists using custom focus node maps.
- [ ] **Carousel Card Scale Adjustments:** Optimize D-pad scale ratios for low-end set-top boxes (e.g. 1.05 limit).

## Phase 2: Playback Diagnostics & Customization
- [ ] **VLC Playback Diagnostics:** Add a togglable debug overlay showing resolution, current framerate, codec, and network buffering status.
- [ ] **Buffer Profiles:** Allow users to switch between "Low Latency" (small buffer) and "Stable" (large buffer) profiles inside player settings.
- [ ] **Network Health Check:** Build a D-pad friendly portal ping test tool to measure connection speeds to the user's provider.

## Phase 3: Accessibility & Internationalization
- [ ] **Localization (i18n):** Add support for Spanish, French, German, Arabic, and Portuguese locales.
- [ ] **Screen Reader Compatibility:** Annotate player buttons and lists with appropriate semantic descriptions.
- [ ] **Better Onboarding:** Add an introductory slide sequence explaining how to connect M3U or Xtream playlists step-by-step.
