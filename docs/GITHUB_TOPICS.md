# Recommended GitHub Topics

To maximize discoverability on GitHub, configure the following topics in your repository settings:

- `flutter`
- `android-tv`
- `iptv-player`
- `m3u-player`
- `xtream-codes`
- `media-player`
- `ott`
- `vlc`
- `flutter-android`
- `tv-app`
- `android-mobile`
- `open-source`

## How to add topics on GitHub

1. Go to the repository homepage on GitHub (`https://github.com/qanvass/tv-parser`).
2. Click the gear icon next to **About** in the right-hand sidebar.
3. Under **Topics**, enter the keywords listed above.
4. Click **Save changes**.
